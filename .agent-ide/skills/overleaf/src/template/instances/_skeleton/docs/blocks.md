# Block catalogue (`<id>`)

> Shared blocks live in `src/template/blocks/`; **write here only the shapes this venue alone has**, landing them in `blocks/<type>.py`.
> Compare the same-named file under `cvpr|fri`: the field contract, the available `block_type`s, and "which kind this venue does not need".

| block_type | Fields | Why this venue needs it (or does not) |
|---|---|---|
| `<type>` | `<field>: <type>` | <one sentence of reason> |

**Do not add a block type** unless the existing ones cannot express the shape: a block type serves **layout**, not one experiment.
