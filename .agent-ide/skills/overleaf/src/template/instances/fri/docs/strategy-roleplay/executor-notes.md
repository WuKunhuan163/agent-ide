# 执行层 · 会场适配（fri）· 最少量

> 这一份**只有会场才说得出的东西**：名词怎么叫、本会场怎样算失败。**层本身的条款在共享 `src/template/docs/strategy-roleplay/03-executor.md`**，两份一起读，missing不可。

**A row.**

one **estimate**: outcome · sample · specification (controls, fixed effects) · data source · build. The estimate without its specification is not comparable to anything, which is why the row carries it rather than a footnote.

So when the answer says "the results table will hold N rows", N is countable in these terms, and a row that lacks one of these fields is a hole with a name, not a row.

**A footing.**

the study whose **specification** the estimate is comparable to — same outcome type, same kind of sample, same controls — not merely a study that also reports an effect. Where no such study exists, the row is `not seen`, and the answer says so instead of borrowing a neighbour's number.

A footing sentence that names a paper without naming the comparable setting is not a footing; it is a citation, and the exam should treat it as one.

**An increment.**

the delta this design buys **on the same specification**, with its cost (data collection, compute, time) named in the same breath. A delta measured on a different specification is a different study, not an increment.

**Disclosure.**

which specifications were fixed **before** the analysis and which **after** — the empirical form of the honesty rule. The answer that cannot separate the two has not understood the venue.

**The four answers.**

- **Q1 (what a finished round leaves).** Rows in the terms above; a footing line per row; sections whose headers name the slot they build; signs for everything that cannot be produced yet. An answer that describes a generic paper's results chapter has not answered this question.
- **Q2 (telling the manuscript aloud).** It must name the stage in this field's own words and say what that stage buys the argument. For this instance the stage is describable as: what was reproduced, what was added, and what the added thing can and cannot claim.
- **Q3 (what each section owes its reader).** Judged against this venue's reading habits: the settings of a number visible where the number is, the protocol named in the same breath as the comparison, the difference sentence quoted from the neighbour rather than summarised.
- **Q4 (the next work).** On-ramp items are the ones that make a run possible in this field: the corpus read for design rather than for decoration, the data that supports the outcome, the table that has a column for every field the row needs, the draft that has a place for the number. In-loop items fill those.

**What fails here.**

An answer that treats significance as the result (rather than the estimate and its interval) fails Q1. An answer that offers a citation where a specification is owed fails Q3. An answer that reports in-loop runs while the sample or the coding is unresolved fails Q4, however correct each run is.


## This venue's delivery contract (three questions, answer only these)

**What is handed over.** One estimate: outcome variable, sample, specification (controls, fixed effects), data source, how it was built — all five before it counts as a row; with it one footing line — why this estimate is comparable with some study's **specification** (same outcome type, same kind of sample, same controls), not "it also reports an effect"; then an increment: what this design buys on the same specification, with its cost (data collection, compute, time) in the same sentence; and finally a disclosure: which specifications were fixed before the analysis and which were changed after seeing results.

**What counts as not handed over.** An estimate with no specification; a footing naming only the study and not the comparable setting; an increment measured on a different specification; a disclosure that cannot tell before from after; significance written as the result. Any one of these and the round has no result in this venue's sense.

**How the receiver judges it.** Put that row into the results table: five cells filled, the comparable setting written in the same row, every blank carrying a name. If yes, it was handed over; if the reader has to hunt the controls in the body text, it was not.

**What it looks like done (what you see opening that directory).** One table, each row with the five provenance cells on the left and the estimate and its interval on the right; footnotes carrying only sources, no hidden specifications. Without that, the work is still in the "it ran" bracket.
