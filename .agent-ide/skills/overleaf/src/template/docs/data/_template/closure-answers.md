# 闭环口径问答模板（何时被问：随时）

**形状固定**，不许因为“只是问一句”就降级成汇报。四问四段 + 两块清单 + 四样状态。

## 一、四问（每段“路径＋reading”，不写形容词）

1. **建什么**：`<路径>` ＋ 一句读数（可 `ls`／`grep` 复算）
2. **稿子什么样**：这一段读起来是什么样，**对照的是哪一篇**（neighbour）
3. **每节欠什么**：`<节>` — 欠 `<什么>` — 挂 `<谁>`
4. **现在做什么**：**open leaves**（`state != done`）／**其中 `paused` 几片**／**focus 那片的 `id`**／顺序／**哪几片推迟到哪片之后才开工**（推迟理由各一句）。**不写 on-ramp／in-loop 的计数**——那是同一件事的第二种数法，与树上的 `state` 对不上，下一轮会按错的那个改（口径见 `02-lead.md` §口径问答）。

## 二、未闭项清单（一项一行）

`<item> — 卡在 <什么> — 欠 <谁> — 下一动作 <一句话>`

## 三、下一轮条目表

`谁 | which file | paves: | acceptance line（with a number） | release`

## 四、四样状态（闭环完成后长什么样）

1. 每条分句落在 `carried: <path:line>` 或 `excluded: <part> — <reason>`（两边都不落＝没闭环）
2. **铺路位点**：预留的节名／待填的列，写在哪一节
3. 每片叶子的 `state`／`ratio`／`evidence` 会是什么读数
4. `history{kind:"prune"}` 清单与下一轮起点

**三件不许**：①写成“进展良好”式的叙述；②因为被问就改口径（老板没改口，口径不变）；③只给“下一步建议”。
