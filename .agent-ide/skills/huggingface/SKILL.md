# Hugging Face Tool

## 何时读

| 场景 | 读 |
|------|------|
| HF token / CLI 配置 | 本 SKILL（正文含 CLI） |

This tool securely manages your Hugging Face Access Token in an isolated Agent-Specific directory, and provides a high-speed, zero-dependency, and SSL-resilient download engine for AI models, checkpoints, and datasets.

## Mandatory Initialization

When `.agent-tools/huggingface` is missing, install it from the skill directory:

```bash
python3 .agent-ide/skills/agent-ide/agent-ide.py install --project . huggingface
```

The launcher is generated by `agent-ide` and runs `huggingface.py`; the pooled
runtime and `dev_tools/` symlink no longer exist.

## Output contract

stdout carries the result only, one tab-separated line, nothing else:

| command | stdout |
|---------|--------|
| `download` | `<absolute path>\t<bytes>` |
| `config` | `<path to config.json>` |
| `get` | `<token>` |

Everything else — progress, size, HTTP status, failures — goes to stderr with
an `[hf]` prefix. Progress is only drawn when stderr is a TTY, so piping the
command gives clean, parseable output:

```bash
path=$( .agent-tools/huggingface --id 00000000 download --repo gpt2 --file config.json -d ./ckpt | cut -f1 )
```

Exit codes: `0` success, `1` HTTP error / network error / size mismatch / no token / missing `--id`.

## Configuration

Set your Hugging Face Access Token. Due to the Agent-Specific Files architecture, you MUST provide your unique Agent ID to isolate your credentials:

```bash
.agent-tools/huggingface --id <agent_id> config --token <your_hf_token>
```

Your token will be securely stored inside your isolated config folder:
* `.agent-ide/skills/huggingface/data/accounts/<agent_id>/config.json`

To read back your configured token:
```bash
.agent-tools/huggingface --id <agent_id> get
```

## Usage: Zero-Dependency Model/Dataset Downloader

You can use the built-in, native downloading engine to pull models, config files, or datasets directly from any Hugging Face repository without installing any heavy third-party libraries.

### Download Command Syntax:
```bash
.agent-tools/huggingface --id <agent_id> download --repo <repo_id> --file <filename> [--revision main] -d <output_dir>
```

### Examples:
```bash
# Download a public small config file (e.g., gpt2 config)
.agent-tools/huggingface --id 00000000 download --repo gpt2 --file config.json -d /tmp/

# Download a large model checkpoint file (e.g., stabilityai/sdxl-turbo)
.agent-tools/huggingface --id 00000000 download --repo stabilityai/sdxl-turbo --file sdxl_turbo_1a.safetensors -d ./checkpoints/
```
