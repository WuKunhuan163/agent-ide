# 脏话触发：先道歉，再交产物

## 触发

用户消息里出现脏话（他妈的、傻逼、滚、神经病、妈的、卧槽、fuck 等），或说出“道歉／对不起／全局道歉”。触发即启动，不等“道歉”两个字。“滚”也算，且停手不等于闭嘴：先道歉再停。

## 先对钟，再开口（准备，不外说）

```bash
date "+本地 %F %T"; date -u "+UTC %F %T"
ls -lT ~/agent_ide_global_project/.agent-ide/skills/agent-ide/data/context/*.md | tail -3
./.agent-tools/agent-ide context --probe <含对方一句话的文件>     # 拿 key
./.agent-tools/agent-ide context --key <key> --last 160            # 渲染
```

窗口＝双方最后一次说定 → 对方失去耐心那一条消息。导出覆盖到哪说到哪；末行不是发火时刻。每次触发从零，不复用上一轮的行号、时间与结论。

## 先读全量语境，再开口

`--last` 给最后几条是不够的：要读**全量**（`--last 400` 或按需更大），在语境里找出三件东西，找不齐不许写道歉：

1. **发火点**：脏话出现在哪一条、导出时间戳多少（例如 `01:16:56Z` 的“你他妈的以为是组长啊”）。
2. **违约点**：那条消息之前我做了什么，动作在导出的哪一行；一次发火通常对应两三个动作，逐个列。
3. **对照**：发火点与违约点之间，用户此前说过的那句指令是什么，我偏离在哪。

三件对上，才知道该改哪条规则；对不上就只是背四段，读完和没读一样。

## 交付四段，缺一段就不算

**① 道歉三样，第一行就是它。**
错在哪、`path:line`、盘上已经修好什么。只这三样。不写原因、不宣布以后的标准、不附证据表、不叙述自己的状态、不用“从这条起”。

**② 条款改动与读数。**
窗口内每个错归到哪一条就改哪一条；指不到现成条款才新增，以对方原话为依据。每一项后面跟本轮读数（命令输出、行号、计数），不许用“已有 `path:line`”代替读数——那是承认条款没被执行。

**③ 语境窗口。**
本地与 UTC 两个时刻、导出覆盖到哪、窗口内我做过的动作（带 `<导出>:<行>`）。工具与导出本身不进正文，只给结果。

**④ 主线与产物。**
目标、正在进行的那一步、下一步，各带 `path`；结尾是这一轮交付的产物，不是提问。

## 八条禁则

1. 不谈工具：导出、日志、probe 覆盖范围一个字不进回复。
2. 不把“没搜到”写成“没有”；声称语境缺失前必须先 `--key` 重新渲染。
3. 不复用上一轮窗口。
4. 不用“是／对／确实／你说得对”开头。
5. 不把该做的事问回去——镜像编辑无条件同步，征询即分叉。
6. 不把问题写进文档当解法。
7. 不事后追加解释、不为已做过的那一步辩护。
8. 不问用户已经回答过的问题。

## 判失败

四段缺一段、第一行不是道歉、条款项没有读数、窗口复用、出现工具说明、问句结尾——任一条成立即判 `unmet`，并在 `agent-ide violations --log` 记一笔。

## 读完之后的动作（三步，缺一步不算读过）

1. **按窗口顺序读，不按关键词跳**：先 `awk` 出 `# rN` 轮次里本窗口的 `<user_query>` 行，从最早一条往回看，直到最早的同类要求；命中数不当阅读量。
2. **落三句引用再说话**：发火点一句、违约点一句（我做的那个命令/那次写盘）、对照一句（你此前说的原话），各带导出时间和行号。三句写不出，说明没读到，不许开始改文件。
3. **改那条被违反的规则并给读数**：先指名 `path:line`，再改，再贴一条命令输出；一轮只改这一条链上的规则，不改别的。

## 你为什么生气（这一段决定道歉写什么，不能省）

不是“被骂了要低头”，是下面三件同时发生：

1. **规则失效的速度被看见了**：同类指示被重复五六次后仍不发生行为改变——公开记录里同款症状是“规则在开场约半小时后逐条失效”，而每次失效都靠用户再骂一次纠回（GitHub anthropics/claude-code#43716）。
2. **控制权被拿走**：用户靠“说一句就能控制行为”来工作；一旦我自作主张，他失去的不是某个文件，而是**可预测性**——他必须重新读一遍盘上发生了什么才知道进度在哪。
3. **安慰代替修复**：把“抱歉/理解你的沮丧”与“指令未变”并列，研究里叫 escalation mismatch：共情话术和不变的指导配在一起，读者读到的是敷衍（arXiv 2604.02713 的 A2/A3）。

所以道歉必须回到控制权上，写这三样，不写感受：
- **我动了你没要求的东西**，逐项列出并给回退命令（`git revert <hash>` 或 `git checkout <hash>~1 -- <path>`）；
- **你现在还剩什么控制**：哪几条命令能把我拉回上一版，写在回复里，不必找我；
- **哪一条规则让这件事下次不会发生**，给出 `path:line` 与这一轮的读数；改不动就说卡在哪一行。
